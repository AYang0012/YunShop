## 1. 框架架构总览

```
                    ┌──────────────────────────┐
                    │     pytest.ini            │  ← 配置入口
                    │     run_tests.py          │  ← 便捷运行入口
                    │     conftest.py           │  ← 全局 fixtures & hooks
                    └──────────────────────────┘
                                  │
              ┌───────────────────┼───────────────────┐
              ▼                   ▼                   ▼
    ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
    │   config/    │   │   utils/     │   │   data/      │
    │ config.py    │   │ driver_*     │   │ test_data.py │
    │ (全局配置)    │   │ logger.py    │   │ *.json       │
    └──────────────┘   │ read_json.py │   └──────────────┘
                       └──────────────┘
                                  │
              ┌───────────────────┼───────────────────┐
              ▼                                       ▼
    ┌──────────────────┐                   ┌──────────────────┐
    │   pages/         │                   │   cases/         │
    │ base_page.py     │ ◄── fixture ───►  │ conftest.py      │
    │ front/*_page.py  │                   │ front/test_*.py  │
    │ admin/*_page.py  │                   │ admin/test_*.py  │
    └──────────────────┘                   └──────────────────┘
                                              │
                                              ▼
                                    ┌──────────────────┐
                                    │   reports/       │
                                    │ allure-results/  │
                                    │ logs/            │
                                    │ screenshots/     │
                                    └──────────────────┘
```

**分层架构（3 层）**:

| 层级 | 目录 | 职责 |
|------|------|------|
| **测试用例层** | `cases/` | 组织和执行测试，使用 pytest + Allure 标记 |
| **页面对象层** | `pages/` | 封装页面元素定位和业务操作（Page Object 模式） |
| **框架基础设施层** | `config/` + `utils/` + `data/` | 配置管理、WebDriver 管理、日志、数据生成 |

## 2. 目录结构与文件说明

### 2.1 根目录文件

| 文件 | 作用 |
|------|------|
| `pytest.ini` | pytest 核心配置文件 — 定义测试路径、运行参数、自定义标记（markers）、Allure 输出目录 |
| `conftest.py` | **全局 conftest** — 最核心的 fixture 文件。提供 `driver`、`base_url`、`test_user`、`admin_user` fixture，以及失败自动截图、Allure environment.properties 生成、Session 生命周期日志 |
| `run_tests.py` | 便捷运行脚本 — 支持 `python run_tests.py [all\|smoke\|regression\|front\|admin\|p0\|p1\|p2]` |
| `.gitignore` | Git 忽略规则 — 排除 `.venv/`、`__pycache__/`、`reports/`、`.idea/` 等 |

### 2.2 `config/` — 配置模块

| 文件 | 作用 |
|------|------|
| `config.py` | **全局配置中心** — 包含所有测试所需的常量（URL、账号、超时、路径、提示文本等） |

### 2.3 `utils/` — 工具模块

| 文件 | 核心职责 |
|------|----------|
| `__init__.py` | 包标识，含模块描述 |
| `driver_factory.py` | **WebDriver 工厂** — 根据配置创建 Chrome/Firefox/Edge 三种浏览器实例，支持本地驱动和自动下载双模式 |
| `logger.py` | **日志工具** — 提供 `get_logger()` 函数，返回控制台 + 按天归档文件双输出的 Logger，使用 `TimedRotatingFileHandler` 保留 7 天日志 |
| `read_json.py` | **JSON 数据读取** — 读取 `data/*.json` 文件，将字典列表转为 `pytest.mark.parametrize` 所需的元组列表 |

### 2.4 `pages/` — Page Object 层

| 文件 | 职责 |
|------|------|
| `base_page.py` | **Page Object 基类** — 封装约 25+ 通用 Selenium WebDriver 操作（详见 [3.3 节](#33-basepage-基类)） |
| `front/` 子包 | **前台页面对象**（12 个页面类，详见 [4.1 节](#41-前台-page-objects)） |
| `admin/` 子包 | **后台页面对象**（7 个页面类，详见 [4.2 节](#42-后台-page-objects)） |

### 2.5 `cases/` — 测试用例层

| 文件 | 职责 |
|------|------|
| `conftest.py` | **用例层 conftest** — 提供所有 Page Object 的 fixture（`login_page`、`home_page` 等），以及 `logged_in`/`admin_logged_in` 复合登录态 fixture |
| `front/` 子包 | **前台测试用例**（7 个测试文件，共 49 条测试用例，详见 [5.1 节](#51-前台测试用例)） |
| `admin/` 子包 | **后台测试用例**（2 个测试文件，共 12 条测试用例，详见 [5.2 节](#52-后台测试用例)） |

### 2.6 `data/` — 测试数据模块

| 文件 | 职责 |
|------|------|
| `test_data.py` | **动态数据生成器** — 生成唯一手机号、邮箱、密码、商品数据、地址数据、订单数据（详见 [6.1 节](#61-test_datapy-动态数据生成器)） |
| `login_data.json` | 登录参数化数据（正确凭证、错误密码、空字段等 4 组） |
| `register_data.json` | 注册参数化数据（成功注册、弱密码、重复手机号等 3 组） |
| `admin_login_data.json` | 后台登录参数化数据（正确、错误密码、空用户名等 3 组） |

### 2.7 `reports/` — 报告输出

| 子目录/文件 | 作用 |
|-------------|------|
| `allure-results/` | Allure 原始测试结果（pytest 运行时自动生成，`.gitignore` 已忽略） |
| `allure-results/environment.properties` | **Allure 环境元数据** — 记录浏览器、BaseURL、API URL、运行时间戳，自动展示在 Allure 报告的 Environment 区域 |
| `logs/` | 测试运行日志（按天归档，`.gitignore` 已忽略） |
| `screenshots/` | 失败自动截图（`.gitignore` 已忽略） |

### 2.8 `.idea/` — IDE 配置

PyCharm 项目配置目录，`.gitignore` 中已忽略，无需上传到 GitHub。

## 3. 核心模块详解

### 3.1 `config/config.py` — 全局配置

```python
# 项目路径
PATH          # config/ 目录的绝对路径

# 被测系统地址
BASE_URL      # "http://localhost:3000"     — 前端地址
API_URL       # "http://localhost:8080/api" — 后端 API

# 浏览器配置
BROWSER       # "chrome" | "firefox" | "edge"
HEADLESS      # False — 是否无头模式
*DRIVER_PATH  # 本地 WebDriver 可执行文件路径

# 超时时间（秒）
IMPLICIT_WAIT  = 10   # 隐式等待
EXPLICIT_WAIT  = 15   # 显式等待（BasePage 默认使用）
PAGE_LOAD_WAIT = 30   # 页面加载超时

# 测试账号
TEST_USER     # {"mobile": "13800138000", "password": "Test@123", ...}
ADMIN_USER    # {"username": "admin", "password": "admin123"}

# 路径
SCREENSHOT_DIR       # 截图保存目录
ALLURE_RESULTS_DIR   # Allure 结果目录
LOG_DIR              # 日志目录
DATA_DIR             # 测试数据目录

# 动态假数据（Faker 生成）
NAME / PHONE / CARD  # 随机中文姓名、手机号、身份证号

# URL 片段常量（22 个）
URL_HOME, URL_LOGIN, URL_REGISTER, URL_GOODS_LIST, ...

# 页面标题常量
TITLE_LOGIN_PAGE, TITLE_REGISTER_PAGE, TITLE_ADMIN_LOGIN_PAGE, LOGO_TEXT

# 提示消息常量（成功 14 个 + 错误 3 个）
MSG_LOGIN_SUCCESS, MSG_REGISTER_SUCCESS, ...

# Element Plus 组件类名常量
CLASS_EL_MESSAGE, CLASS_EL_MESSAGE_BOX, CLASS_EL_EMPTY, ...
```

### 3.2 `utils/driver_factory.py` — WebDriver 工厂

| 函数 | 签名 | 职责 |
|------|------|------|
| `create_driver()` | `() -> WebDriver` | 根据 `BROWSER` 配置创建对应浏览器的 WebDriver 实例，设置隐式等待 + 页面加载超时 |
| `_create_chrome()` | `() -> WebDriver` | 创建 Chrome WebDriver（1920×1080，支持 headless） |
| `_create_firefox()` | `() -> WebDriver` | 创建 Firefox WebDriver |
| `_create_edge()` | `() -> WebDriver` | 创建 Edge WebDriver |
| `_get_service()` | `(local_path, ServiceCls, webdriver_manager_path) -> Service` | 驱动优先级：本地路径 > webdriver-manager 自动下载 > 系统 PATH |

### 3.3 `BasePage` 基类

`BasePage` 是所有 Page Object 的基类，封装了约 **25+ 个通用 WebDriver 操作方法**，分为以下功能组：

#### 页面导航（3个方法）
| 方法 | 职责 |
|------|------|
| `open(url)` | 导航到指定 URL（带 `@allure.step` 报告） |
| `refresh()` | 刷新当前页面 |
| `current_url` / `page_title` | 属性，返回当前 URL / 页面标题 |

#### 元素查找（6个方法）
| 方法 | 职责 |
|------|------|
| `find(locator, timeout)` | 等待元素**可见**后返回（最常用） |
| `find_present(locator, timeout)` | 等待元素**存在于 DOM**（不要求可见） |
| `find_all(locator, timeout)` | 查找**所有可见**元素 |
| `find_all_present(locator, timeout)` | 查找**所有存在于 DOM** 的元素 |
| `is_displayed(locator, timeout)` | 判断元素是否可见（短超时 3s，不抛异常） |
| `is_present(locator, timeout)` | 判断元素是否存在于 DOM |
| `element_count(locator)` | 返回匹配元素数量 |

#### 元素操作（3个方法）
| 方法 | 职责 |
|------|------|
| `click(locator, timeout)` | 点击元素（内置点击被拦截重试） |
| `click_js(locator)` | JavaScript 强制点击（绕过可见性检查） |
| `type(locator, text, clear_first)` | 输入文本（先清空再输入） |

#### 内容读取（3个方法）
| `get_text(locator)` | 获取元素文本 |
| `get_attribute(locator, attr)` | 获取元素属性值 |
| `get_value(locator)` | 获取输入框当前值 |

#### 等待 & 判断（5个方法）
| `wait_for_clickable(locator, timeout)` | 等待元素可点击 |
| `wait_for_invisible(locator, timeout)` | 等待元素不可见（常用于 loading 消失） |
| `wait_for_text(locator, text, timeout)` | 等待元素包含指定文本 |
| `wait_for_url_contains(fragment, timeout)` | 等待 URL 包含指定字符串 |
| `_pause(seconds)` | 固定等待（**已弃用**，仅用于极少数过渡动画） |

#### 滚动 & 鼠标（5个方法）
| `_scroll_to(element)` | 滚动到元素中央（`block: center`） |
| `scroll_to(locator)` | 滚动到指定元素 |
| `scroll_to_bottom()` | 滚动到页面底部 |
| `scroll_to_top()` | 滚动到页面顶部 |
| `hover(locator)` | 鼠标悬停到元素（ActionChains） |

#### 下拉 & 复选框（3个方法）
| `select_by_text(locator, text)` | 原生 `<select>` 按文本选择 |
| `select_by_value(locator, value)` | 原生 `<select>` 按 value 选择 |
| `checkbox_check(locator, check)` | 勾选/取消勾选复选框 |

#### Alert / 弹窗（2个方法）
| `accept_alert(timeout)` / `dismiss_alert(timeout)` | 接受/取消 alert，返回弹窗文本 |

#### 窗口 / Frame（4个方法）
| `switch_to_new_window()` / `switch_to_main_window()` | 窗口切换 |
| `switch_to_frame(locator)` / `switch_to_default_content()` | iframe 切换 |

#### 截图（1个方法）
| `screenshot(filename)` | 保存截图到截图目录 |

#### Element Plus 组件专用（4个方法）
| 方法 | 职责 |
|------|------|
| `el_select_option(placeholder, option_text)` | Element Plus 下拉选择（点击触发 → 点击选项） |
| `el_message_should_contain(text)` | 验证 Element Plus Message 是否包含指定文本 |
| `el_dialog_confirm()` | 点击 Dialog/MessageBox 确认按钮 |
| `el_dialog_cancel()` | 点击 Dialog/MessageBox 取消按钮 |

### 3.4 `utils/logger.py` — 日志模块

| 函数 | 签名 | 职责 |
|------|------|------|
| `get_logger(name)` | `(str) -> Logger` | 返回配置好的 Logger，控制台输出 INFO 级别，文件按天归档保留 7 天，文件记录 DEBUG 级别 |

### 3.5 `utils/read_json.py` — JSON 数据读取

| 函数 | 签名 | 职责 |
|------|------|------|
| `read_json(filename)` | `(str) -> list[tuple]` | 读取 `data/{filename}`，将 `[{"k": "v"}, ...]` 转为 `[("v",), ...]` 格式，用于 pytest parametrize |

## 4. Page Object 层详解

> 所有 Page Object 遵循统一模式：继承 `BasePage` → 定义 `URL` 类属性 → 定义 CSS/XPath 元素定位器 → 实现业务方法。

### 4.1 前台 Page Objects

#### `HomePage` — 首页
- **URL**: `/`
- **定位器（21 个）**: 分类菜单、Banner 轮播、商品楼层、热门推荐、商品卡片通用
- **核心方法（16 个）**:
  - **分类菜单**: `get_category_count()`, `get_category_names()`, `hover_category(index)`, `is_popup_visible()`, `get_popup_titles()`, `click_category(index)` — 支持悬停弹出子分类
  - **Banner 轮播**: `get_banner_count()`, `is_banner_displayed()`, `click_next_banner()`, `click_prev_banner()`, `click_dot(index)`, `hover_banner()` — 支持箭头切换、指示器点击、悬停暂停
  - **商品楼层**: `get_floor_count()`, `get_floor_titles()`, `get_floor_goods_count()`, `click_floor_goods()` — 支持按楼层索引操作
  - **热门推荐**: `get_hot_goods_count()`, `is_hot_section_displayed()`, `click_hot_goods(index)`
  - **通用**: `click_goods_card(index)`, `is_home_page()`

#### `LoginPage` — 会员登录
- **URL**: `/login`
- **定位器（9 个）**: 用户名、密码、验证码输入框，验证码按钮，提交按钮，注册/首页链接，表单错误
- **核心方法（8 个）**:
  - `login(username, password, captcha="dev")` — 完整登录流程（含获取验证码）
  - `get_captcha_text()` — 获取验证码
  - `get_title_text()`, `get_form_errors()`, `is_login_page()`
  - `go_register()`, `go_home()` — 页面跳转

#### `RegisterPage` — 会员注册
- **URL**: `/register`
- **定位器（11 个）**: 手机号/邮箱 Tab，账号/密码/确认密码/推荐人输入框，协议复选框，提交按钮，跳转链接
- **核心方法（7 个）**:
  - `register(account, password, confirm_password, register_type, referrer, agree_protocol)` — 完整注册流程
  - `switch_to_email()`, `switch_to_mobile()` — 切换注册方式
  - `get_title_text()`, `get_form_errors()`, `is_register_page()`, `go_login()`

#### `GoodsListPage` — 商品列表
- **URL**: `/goods/list?catId=...&keyword=...`
- **定位器（18 个）**: 搜索框/按钮，排序栏（综合/销量/价格/新品），每页条数（12/24/48），商品网格，分页，空状态
- **核心方法（17 个）**:
  - `open(cat_id, keyword)` — 支持分类 ID 和关键词参数
  - `search(keyword)`, `get_search_keyword()`
  - `sort_by_default()`, `sort_by_sales()`, `sort_by_price()`, `sort_by_time()` — 排序
  - `set_page_size(size)` — 切换每页条数
  - `get_goods_count()`, `get_goods_names()`, `get_goods_prices()`, `click_goods(index)`, `is_empty()`
  - `get_current_page()`, `click_next_page()`, `click_prev_page()`, `click_page(num)` — 分页操作
  - `go_home()`, `go_cart()` — 导航

#### `GoodsDetailPage` — 商品详情
- **URL**: `/goods/detail/{goodsId}`
- **定位器（14 个）**: 商品主图、标题、描述、价格、销量、库存、数量控件、购物车/购买按钮、详情内容
- **核心方法（15 个）**:
  - `url_for(goods_id)` — 静态方法，生成详情 URL
  - `open(goods_id)` — 默认打开商品 #1
  - `get_goods_name()`, `get_shop_price()`, `get_market_price()`, `get_store_count()`, `get_sales_count()`
  - `get_buy_quantity()`, `set_quantity(num)`, `increase_quantity(times)`, `decrease_quantity(times)` — 数量操作
  - `add_to_cart()`, `buy_now()` — 核心操作
  - `is_detail_page()`, `has_detail_content()`, `go_cart()`, `go_home()`

#### `CartPage` — 购物车
- **URL**: `/cart`（需登录）
- **定位器（18 个）**: 购物车表格，全选/行选中，商品名/属性/价格/数量/小计，删除/批量删除，结算按钮，空状态，确认对话框
- **核心方法（14 个）**:
  - `get_item_count()`, `is_empty()`, `get_empty_text()`
  - `toggle_select_all()`, `is_all_selected()`, `toggle_row_selection(index)`
  - `update_quantity(row_index, num)`, `delete_item(row_index)`, `delete_selected(confirm)`
  - `get_item_names()`, `get_selected_count()`, `get_total_price()`
  - `go_checkout()`, `is_checkout_enabled()`, `continue_shopping()`, `go_home()`

#### `OrderConfirmPage` — 订单确认
- **URL**: `/order/confirm`（需登录）
- **定位器（11 个）**: 地址区域，商品清单，支付方式（支付宝/微信/银联/货到付款），配送方式，备注，总金额，提交按钮
- **核心方法（5 个）**:
  - `select_pay_method(pay_name)` — 选择支付方式
  - `type_remark(remark)` — 填写备注
  - `submit_order()` — 提交订单
  - `get_total_amount()`, `is_confirm_page()`

#### `UserCenterPage` — 用户中心
- **URL**: `/user`（需登录）
- **定位器（5 个）**: 我的订单/收货地址/个人信息/修改密码导航链接
- **核心方法（7 个）**:
  - `go_orders()`, `go_address()`, `go_profile()`, `go_password()` — 导航到各子页面
  - `is_user_center()`, `go_home()`

#### `UserOrdersPage` — 我的订单
- **URL**: `/user/orders`（需登录）
- **定位器（14 个）**: 状态 Tab（全部/待付款/待发货/待收货/已完成/已取消），订单项，操作按钮（付款/取消/收货/详情），空状态
- **核心方法（7 个）**:
  - `filter_by_status(status)` — 按状态筛选
  - `get_order_count()`, `is_empty()`, `get_order_sns()`
  - `click_order_detail(index)`, `pay_order(index)`, `cancel_order(index)`, `confirm_receive(index)`

#### `UserAddressPage` — 收货地址
- **URL**: `/user/address`（需登录）
- **定位器（12 个）**: 地址项，新增/编辑/删除/默认按钮，收货人/手机/省/市/区/详细地址输入框
- **核心方法（5 个）**:
  - `add_address(consignee, mobile, ...)` — 完整新增地址
  - `delete_address(index)` — 删除（含确认对话框）
  - `set_default(index)`, `edit_address(index, **kwargs)`
  - `get_address_count()`, `is_empty()`

### 6.1 `test_data.py` — 动态数据生成器

每次调用生成唯一数据，通过时间戳 + 随机字符串避免数据库冲突。

| 函数 | 返回 | 说明 |

| `random_digits(length)` | `str` | 随机数字串 |
| `new_mobile()` | `str` | 未注册手机号（1[3-9] 开头，11 位） |
| `new_email(username)` | `str` | 未注册邮箱（@126/sina/qq/163.com） |
| `valid_password()` | `str` | 合规密码，固定 `"Test@123"` |
| `weak_password()` | `str` | 弱密码 `"123456"` |
| `new_goods_data()` | `dict` | 商品数据 {goods_name, goods_sn, shop_price, market_price, store_count, goods_content} |
| `new_address_data()` | `dict` | 地址数据 {consignee, mobile, province, city, district, address} |
| `new_order_data()` | `dict` | 订单数据 {pay_name, shipping_name, remark} |

## 8. 代码执行流程

### 8.1 完整执行时序

```
pytest 启动
    │
    ├── [pytest_configure]          ← 读取 --alluredir，生成环境信息
    │       └── 写入 reports/allure-results/environment.properties
    │       └── 创建 screenshots/ 目录
    │
    ├── [pytest_sessionstart]       ← 打印测试开始日志
    │
    ├── [Session fixture 初始化]
    │       └── base_url, api_url, test_user, admin_user  → 返回配置值
    │
    └── [每个测试用例循环]
            │
            ├── [Function fixture: driver]
            │       ├── create_driver()    ← 根据 BROWSER 创建 WebDriver
            │       ├── maximize_window()
            │       ├── yield driver       ← 传递给测试用例
            │       └── driver.quit()      ← 测试结束后关闭浏览器
            │
            ├── [Conftest fixture: xxx_page]
            │       └── 实例化 Page Object(page_page(driver)) → 返回给测试用例
            │
            ├── [Conftest fixture: logged_in / admin_logged_in]（如果需要）
            │       └── login_page.open() + login() → 预置登录态 → 返回用户数据
            │
            ├── [测试函数体执行]
            │       ├── page.open()        ← 导航到目标页面
            │       ├── page.xxx_method()  ← 执行业务操作（点击、输入等）
            │       └── assert ...         ← 验证结果
            │
            ├── [pytest_runtest_makereport]  ← 每个测试完成后
            │       ├── if 失败:
            │       │   ├── driver.save_screenshot()     ← 自动截图
            │       │   └── allure.attach.file()          ← 附加到 Allure 报告
            │       └── if 失败:
            │           └── driver.get_log("browser")     ← 附加浏览器控制台日志
            │
            └── [下一个测试用例]
                    ↓
    └── [pytest_sessionfinish]      ← 打印测试结束日志
```

### 8.2 Fixture 依赖关系

```
driver (function scope)
    │
    ├── home_page(driver)
    ├── login_page(driver)
    ├── register_page(driver)
    ├── goods_list_page(driver)
    ├── ... (所有 Page Object fixtures)
    │
    ├── logged_in(driver, login_page, test_user)
    │     └── login_page.open() + login()  → 返回 test_user
    │
    └── admin_logged_in(driver, admin_login_page, admin_user)
          └── admin_login_page.open() + login()  → 返回 admin_user

test_user (session scope)  ← 来自 config.TEST_USER
admin_user (session scope) ← 来自 config.ADMIN_USER
base_url (session scope)   ← 来自 config.BASE_URL
api_url (session scope)    ← 来自 config.API_URL
```

### 8.3 conftest 的两次覆盖

```
tests/conftest.py          ← 全局 conftest（driver, test_user, hooks...）
tests/cases/conftest.py    ← 用例层 conftest（所有 Page Object fixtures）
```

pytest 会自动合并两个 conftest：测试用例可以同时使用 `driver` 和 `login_page`。

```python
# 1. 创建 pages/front/xxx_page.py
from pages.base_page import BasePage
from config.config import BASE_URL

class XxxPage(BasePage):
    URL = f"{BASE_URL}/xxx"

@pytest.fixture
def xxx_page(driver):
```

```ini
markers =

```

```python
from utils.read_json import read_json
```
