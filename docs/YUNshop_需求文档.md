## 一、用户角色

| 角色 | 前台/后台 | 权限说明 |
|------|-----------|----------|
| 游客 | 前台 | 未登录，仅可浏览商品、注册 |
| 注册会员 | 前台 | 登录后可购买商品、管理订单、管理收货地址、评价晒单 |

## 二、前台功能需求

### 2.1 导航栏

- 显示 **前8条** 导航数据
- 按排序字段逆序展示
- 未登录：头部显示「登录」「注册」链接
- 已登录：显示用户名 +「安全退出」

### 2.2 登录功能

| 功能点 | 规则 |
|--------|------|
| 登录方式 | 用户名（手机号/邮箱）+ 密码 |
| 验证码 | 必须输入，点击可刷新，不可重用 |
| 第三方登录 | 支持支付宝、QQ、微信 |
| 登录成功 | 跳转「我的商城」页面 |
| 登录失败 | 停留在登录页，显示错误提示 |
| 安全退出 | 点击用户名后的「安全退出」 |

### 2.3 注册功能

| 功能点 | 规则 |
|--------|------|
| 注册方式 | 默认手机号注册，可切换邮箱注册 |
| 手机号规则 | 11位，第一位为1，第二位非2 |
| 邮箱规则 | `xxxx@[126/sina/qq/163].com`，xxxx 长度4-16位，数字/字母/下划线，不能以下划线开头 |
| 密码规则 | 6-16位，大小写英文 + 数字 + 符号（至少两种组合） |
| 确认密码 | 必须与密码一致 |
| 推荐人手机 | 非必填 |
| 协议勾选 | 必须勾选「我已阅读并同意」协议 |
| 注册成功 | 跳转首页，自动登录状态，后台会员总数+1 |

### 2.4 首页

#### 全部商品分类
- 默认显示 **6个** 一级分类
- 鼠标移入一级分类 → 背景变浅，展示该分类下所有二、三级分类
- 鼠标移入子分类 → 字体变红
- 点击分类 → 跳转对应商品列表（筛选条件）
- 数据来源：`goods_category` 表，`level` 字段标识层级，`parent_id` 标识父子关系

#### Banner 轮播图
- 显示 **1-5张** banner
- 自动轮播，**3秒** 切换一张
- 仅1张时不轮播
- 鼠标悬停 → 停止轮播
- 点击图片 → 跳转对应商品详情页
- 支持：实心指示器点击跳转、左右箭头切换

#### 商品分类楼层
- 由一级分类的 `is_hot` 字段控制楼层是否显示
- 显示：楼层一级分类名称 + 二级分类链接
- 当前楼层显示对应分类前 **6条** 在售商品
- 热门推荐：默认显示 **4个** 商品，轮播展示（按 `is_recommend` 筛选）
- 「更多」按钮 → 进入当前楼层一级分类的商品列表页
- 两个广告位，点击跳转商品详情

### 2.5 商品列表页

- 支持按分类筛选
- 支持按价格排序（升/降）
- 支持按销量排序
- 支持按上架时间排序
- 分页展示，每页12/24/48条可选
- 显示：商品缩略图、名称、价格、销量、评价数
- 支持关键词搜索

### 2.6 商品详情页

- 商品主图 + 多张轮播图
- 商品名称、价格（原价 + 促销价）、销量、库存
- 商品规格选择（颜色、尺码等 SKU）
- 购买数量选择（1-库存数）
- 「加入购物车」按钮
- 「立即购买」按钮
- 商品描述（图文详情）
- 商品评价列表
- 收藏商品

### 2.7 购物车

#### 显示规则

| 规则 | 说明 |
|------|------|
| 空购物车 | 提示「购物车还没有任何商品，马上去购物」 |
| 有商品时 | 显示：商品图片、名称、单价、数量、小计 |
| 价格 | 与加入购物车时的价格一致 |

#### 限制规则

| 限制 | 值 |
|------|-----|
| 单个商品最小数量 | 1 |
| 单个商品最大数量 | 200 |
| 购物车商品种类上限 | 20种 |

#### 操作功能

| 操作 | 说明 |
|------|------|
| 加入购物车 | 从详情页/列表页点击加入，受数量限制，考虑库存 |
| 修改数量 | +/- 按钮 或 直接输入数字（范围 1-200） |
| 删除单个 | 点击 × 删除 |
| 批量删除 | 勾选多个后点击删除 |
| 全选 | 全选/取消全选 |
| 删除全部 | 全选后批量删除 |
| 点击图片/名称 | 跳转商品详情页 |
| 继续购物 | 跳转商品页面 |
| 去结算 | 跳转填写核对订单页 |

#### 金额计算
- 小计 = 单价 × 数量
- 显示已选择件数总和
- 显示合计总价

### 2.8 订单流程

#### 下单流程
```
浏览商品 → 加入购物车 → 购物车结算 → 确认订单 → 提交订单 → 支付 → 完成
```

如果是未登录用户：
```
浏览商品 → 加入购物车 → 提示登录/注册 → 登录 → 购物车结算 → ...
```

#### 确认订单页
- 选择/新增收货地址
- 确认商品清单（商品、单价、数量、小计）
- 选择配送方式
- 选择支付方式（支付宝/微信/银联/货到付款）
- 订单备注（选填）
- 显示订单总金额（商品总价 + 运费 - 优惠）
- 「提交订单」按钮

#### 订单状态流转

```
PENDING（待付款）
  ├→ 支付成功 → PAID（已付款/待发货）
  │               ├→ 发货 → SHIPPED（已发货）
  │               │          ├→ 确认收货 → COMPLETED（已完成）
  │               │          │               ├→ 评价 → （已评价）
  │               │          ├→ 申请退货 → RETURNING（退货中）
  │               │          │               ├→ 退款 → REFUNDED（已退款）
  │               └→ 取消（未发货可取消）→ CANCELLED（已取消）
  └→ 超时未支付 → CANCELLED（自动取消）
```

### 2.9 用户中心

## 五、业务流程

### 主流程：用户购物
```
1. 游客访问首页
2. 浏览商品分类/搜索商品
3. 查看商品详情
4. 加入购物车 → 系统提示登录
5. 注册/登录
6. 回到购物车 → 去结算
7. 选择/新增收货地址
8. 选择支付方式
9. 确认订单信息 → 提交订单
10. 跳转支付 → 完成支付
11. 等待发货 → 确认收货 → 评价
```

### 异常流程
- 库存不足 → 提示"库存不足，无法购买"
- 未登录下单 → 跳转登录页
- 支付超时 → 订单自动取消，库存回滚
- 重复支付 → 防止重复扣款
- 并发下单 → 库存原子扣减，超卖防护
